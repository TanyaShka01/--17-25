Рекомендации по исправлению коммитов (Conventional Commits)
===========================================================

Проблема: Коммиты не соответствуют спецификации Conventional Commits
Коммиты: 6145969, c9ba5c9, 5146aa5, 14d9343, 9efdef6

Формат Conventional Commits:
<type>(<scope>): <description>

Типы коммитов:
- feat: новая функциональность
- fix: исправление ошибки
- docs: изменения в документации
- style: форматирование кода
- refactor: рефакторинг кода
- test: добавление/изменение тестов
- chore: изменения в конфигурации, зависимостях

Примеры правильных коммитов:
- feat(depvis): add PNG image generation
- fix(cli): correct argument parsing
- docs(readme): update installation instructions
- refactor(exporters): simplify image creation logic

ВАЖНО: Переписывать историю коммитов (git rebase) опасно, если репозиторий
уже опубликован или используется другими разработчиками.

Рекомендуемые действия:
1. Для новых коммитов используйте правильный формат
2. Если это личный проект и история еще не опубликована, можно использовать:
   git rebase -i HEAD~5
   и изменить сообщения коммитов

3. Если репозиторий уже опубликован, продолжайте работу с правильными
   коммитами, старые оставьте как есть
