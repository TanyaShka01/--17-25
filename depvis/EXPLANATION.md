# Инструмент визуализации графа зависимостей пакетов Python

## Как запустить программу

### Базовый запуск
```bash
python depvis.py
```
Использует файл `config.ini` по умолчанию.

### Запуск с другой конфигурацией
```bash
python depvis.py config_pandas.ini
python depvis.py config_cyclic.ini
```

## Примеры использования

### Пример 1: Анализ Flask
```bash
python depvis.py
```
Анализирует зависимости пакета Flask версии 2.0.0

### Пример 2: Анализ Pandas
```bash
python depvis.py config_pandas.ini
```

### Пример 3: Обнаружение циклов
```bash
python depvis.py config_cyclic.ini
```

## Как работает программа

### Архитектура

Программа состоит из одного класса `DependencyVisualizer`, который выполняет все этапы работы:

1. **Инициализация и чтение конфигурации**
   - Загружает INI-файл с помощью `configparser`
   - Извлекает параметры: имя пакета, URL репозитория, режим работы, версию, настройки вывода

2. **Получение информации о пакетах** (`fetch_package_info`)
   - В тестовом режиме: читает данные из локального JSON-файла
   - В реальном режиме: делает HTTP-запрос к PyPI API
   - Возвращает список зависимостей для указанной версии пакета

3. **Парсинг зависимостей** (`parse_dependency`)
   - Обрабатывает строки формата "package==version"
   - Поддерживает операторы: ==, >=
   - Игнорирует условия после точки с запятой (например, условия платформы)

4. **Построение графа зависимостей** (`build_graph_dfs`)
   - Использует **алгоритм DFS (Depth-First Search) без рекурсии**
   - Применяет стек для обхода графа
   - Отслеживает глубину для ограничения по `max_depth`
   - Помечает посещённые узлы для избежания повторной обработки
   - Строит словарь `graph`: {пакет: [список_зависимостей]}

5. **Поиск обратных зависимостей** (`find_reverse_dependencies`)
   - Перебирает все записи в графе
   - Ищет пакеты, в зависимостях которых есть целевой пакет
   - Возвращает список пакетов, зависящих от данного

6. **Обнаружение циклических зависимостей** (`detect_cycles`)
   - Использует модифицированный DFS
   - Отслеживает текущий путь обхода
   - Если встречается узел, уже находящийся в пути - обнаружен цикл
   - Сохраняет цепочку пакетов, образующих цикл

7. **Визуализация ASCII-дерева** (`generate_ascii_tree`)
   - Рекурсивно обходит граф от корня
   - Использует символы для отрисовки структуры дерева:
     - `├──` для промежуточных элементов
     - `└──` для последних элементов
     - `│` для вертикальных линий
   - Отслеживает посещённые узлы для пометки циклов как "(circular)"

8. **Генерация D2-диаграммы** (`generate_d2_diagram`)
   - Создаёт текстовое представление графа в формате D2
   - Определяет направление: слева направо
   - Для каждого узла создаёт описание
   - Для каждого ребра создаёт связь (->)
   - Заменяет специальные символы в именах на подчёркивания

### Ключевые алгоритмы

#### DFS без рекурсии
```python
stack = [(package, version, depth)]
while stack:
    pkg, ver, depth = stack.pop()
    # Обработка узла
    # Добавление детей в стек
```

Преимущества:
- Избегает ограничений глубины рекурсии Python
- Позволяет контролировать порядок обхода
- Эффективно по памяти

#### Обнаружение циклов
Использует отслеживание пути:
- Если узел встречается в текущем пути - найден цикл
- Сохраняет участок пути от начала цикла до повторной встречи

### Форматы данных

#### Входной INI-файл
```ini
[Settings]
package_name = flask
repo_url = test_repo.json
test_mode = true
package_version = 2.0.0
ascii_tree = true
max_depth = 2
```

#### Тестовый репозиторий (JSON)
```json
{
  "flask==2.0.0": ["werkzeug==2.0.0", "jinja2==3.0.0"],
  "werkzeug==2.0.0": ["markupsafe==2.0.0"]
}
```

#### Выходные данные
1. Параметры конфигурации
2. Прямые зависимости
3. Обратные зависимости
4. Обнаруженные циклы
5. ASCII-дерево
6. D2-диаграмма

### Особенности реализации

#### Обработка ошибок
- При недоступности пакета в репозитории создаётся пустой список зависимостей
- В реальном режиме перехватываются исключения HTTP-запросов

#### Ограничения
- `max_depth` предотвращает бесконечный обход при циклах
- Посещённые узлы не обрабатываются повторно в одном обходе

#### Особенности визуализации
- ASCII-дерево помечает циклические ссылки как "(circular)"
- D2-формат заменяет дефисы и точки на подчёркивания для валидных идентификаторов

```
├── config_pandas.ini      # Конфигурация для Pandas
├── config_cyclic.ini      # Конфигурация для тестирования циклов
├── test_repo.json         # Тестовый репозиторий с данными о пакетах

```

## Требования

- Python 3.6 или выше
- Стандартная библиотека (встроенные модули):
  - configparser
  - json
  - urllib.request
  - collections
  - sys

Никаких внешних зависимостей не требуется.

## Этапы выполнения работы (согласно заданию)

### Этап 1: Минимальный прототип с конфигурацией ✓
- CLI-приложение с параметрами из INI-файла
- Обработка всех параметров конфигурации
- Вывод параметров при запуске
- Валидация и обработка ошибок

### Этап 2: Сбор данных ✓
- Получение информации о зависимостях через URL или локальный файл
- Использование формата pip (Python пакеты)
- Извлечение прямых зависимостей для указанной версии
- Вывод всех прямых зависимостей на экран

### Этап 3: Основные операции ✓
- Построение графа с использованием DFS без рекурсии
- Анализ с учётом максимальной глубины
- Обработка циклических зависимостей
- Поддержка тестового режима (локальный JSON)

### Этап 4: Дополнительные операции ✓
- Поиск обратных зависимостей
- Алгоритм обхода графа для поиска зависимых пакетов

### Этап 5: Визуализация ✓
- Генерация текстового представления в формате D2
- Вывод описания графа на языке диаграмм
- Опциональный вывод ASCII-дерева
- Демонстрация для трёх разных пакетов (Flask, Pandas, циклические)
