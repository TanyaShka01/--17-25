Инструкция по установке зависимостей для создания изображений
================================================================

Для создания PNG изображений графов зависимостей необходимо установить:

pip install -r requirements.txt

Или вручную:

pip install matplotlib networkx

После установки запустите утилиту:

run.bat config.ini

Изображение будет сохранено в папке ep5_output с именем <package_name>_deps.png
