# Визуализатор графа зависимостей пакетов

## Описание

Инструмент для анализа и визуализации зависимостей пакетов Python (pip).

## Запуск

```bash
python depvis.py [путь_к_config.ini]
```

Если конфигурационный файл не указан, используется `config.ini` по умолчанию.

### Примеры запуска

```bash
python depvis.py
python depvis.py config.ini
python depvis.py custom_config.ini
```

## Конфигурация (config.ini)

```ini
[Settings]
package_name = flask
repo_url = test_repo.json
test_mode = true
package_version = 2.0.0
ascii_tree = true
max_depth = 2
```

Параметры:
- `package_name` - имя анализируемого пакета
- `repo_url` - URL репозитория PyPI или путь к тестовому JSON-файлу
- `test_mode` - режим работы (true = локальный JSON, false = реальный PyPI)
- `package_version` - версия пакета
- `ascii_tree` - вывод зависимостей в виде ASCII-дерева (true/false)
- `max_depth` - максимальная глубина анализа зависимостей

## Тестирование с разными пакетами

### Пример 1: Flask
```ini
package_name = flask
package_version = 2.0.0
```

### Пример 2: Django
```ini
package_name = django
package_version = 3.2.0
```

### Пример 3: Pandas
```ini
package_name = pandas
package_version = 1.3.0
```

### Пример 4: Циклические зависимости
```ini
package_name = cyclic-a
package_version = 1.0.0
```

## Как работает программа

### Этап 1: Загрузка конфигурации
Программа читает INI-файл и извлекает параметры анализа.

### Этап 2: Сбор данных о зависимостях
Используется алгоритм DFS (обход в глубину) без рекурсии:
- Начинает с корневого пакета
- Получает список его прямых зависимостей
- Для каждой зависимости рекурсивно извлекает её зависимости
- Ограничивается параметром max_depth

В тестовом режиме данные берутся из локального JSON-файла.
В режиме реального репозитория - обращается к PyPI API.

### Этап 3: Построение графа зависимостей
Граф хранится как словарь: {пакет: [список_зависимостей]}

### Этап 4: Анализ графа

#### Прямые зависимости
Выводит список пакетов, от которых напрямую зависит анализируемый пакет.

#### Обратные зависимости
Находит пакеты, которые зависят от данного пакета.

#### Обнаружение циклов
Алгоритм DFS с отслеживанием пути для выявления циклических зависимостей.

### Этап 5: Визуализация

#### ASCII-дерево
Древовидное представление с символами:
- `├──` - промежуточная ветка
- `└──` - последняя ветка
- `│` - продолжение линии

#### Диаграмма D2
Текстовый формат для создания графических диаграмм:
- Определяет узлы (пакеты)
- Определяет рёбра (зависимости)
- Можно визуализировать через внешние инструменты D2

## Структура выходных данных

1. Параметры конфигурации (ключ=значение)
2. Список прямых зависимостей
3. Список обратных зависимостей
4. Обнаруженные циклы (если есть)
5. ASCII-дерево (если включено)
6. D2-диаграмма

## Требования

- Python 3.6+
- Стандартная библиотека (configparser, json, urllib)
