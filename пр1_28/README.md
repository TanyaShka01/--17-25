# Вариант №28 — эмулятор оболочки, этап 1 (REPL)

Минимальный консольный прототип на Python. Реализованы три требования,
видимые на предоставленном изображении задания.

## Требования и реализация

1. **CLI:** цикл ввода и вывода в терминале (`emulator/shell.py`).
2. **Имя VFS в приглашении:** по умолчанию `VFS:/$ `; имя настраивается.
3. **Простой парсер:** `str.split()` выделяет первое слово как команду,
   остальные — как аргументы (`emulator/parser.py`). Повторные пробелы,
   табуляции и пробелы по краям пропускаются. Пустая строка игнорируется.

## Структура

```text
shell_variant28/
├── main.py                 # запуск и параметры CLI
├── emulator/

│   ├── commands.py         # обработчики и заглушки
│   └── shell.py            # приглашение и цикл REPL
├── tests/

```

## Запуск

Нужен Python 3.8 или новее. Сторонние библиотеки не требуются.
Распакуйте архив и откройте терминал в папке `shell_variant28`.

```bash
python main.py
```

В Linux/macOS при необходимости используйте `python3` вместо `python`.
Для настройки имени VFS:

```bash
python main.py --vfs-name StudyVFS
```

Справка параметров запуска: `python main.py --help`.

## Команды

| Команда | Поведение |
| --- | --- |
| `help` | Показывает справку |
| `exit` | Завершает REPL |
| `ls`, `cd`, `pwd`, `cat` | Выводят имя команды и список аргументов |
| Неизвестная команда | Сообщает «команда не найдена» |

`help` и `exit` принимаются без аргументов. При лишних аргументах
выводится подсказка, программа продолжает работу.
`Ctrl+C` отменяет ввод и возвращает приглашение. EOF завершает программу:
обычно `Ctrl+D` в UNIX или `Ctrl+Z`, затем Enter в Windows.

## Пример

```text
VFS:/$ ls -l /home
Команда: ls
Аргументы: ['-l', '/home']
Функция пока не реализована (этап 1).
VFS:/$ unknown
unknown: команда не найдена
VFS:/$ exit
Работа эмулятора завершена.
```

## Границы первого этапа

VFS пока представлена именем; архив или дерево файлов не загружается.
Путь `/` в приглашении фиксированный. `cd` не меняет каталог.
Команды не запускаются в настоящей оболочке и не изменяют файлы компьютера.
Кавычки, экранирование, перенаправления, конвейеры и переменные не
обрабатываются: например, `cat "my file.txt"` даст два аргумента
`'"my'` и `'file.txt"'`. Это соответствует простому разбору по пробелам.
Набор заглушек выбран для демонстрации диалога: на изображении конкретный
набор команд не указан.

## Проверка

Из корня проекта:

```bash
python -m unittest discover -s tests -v
```

Проверяются парсер, пустой ввод, приглашение с именем VFS, заглушки,
неизвестная команда, выход, EOF и продолжение работы после Ctrl+C.
